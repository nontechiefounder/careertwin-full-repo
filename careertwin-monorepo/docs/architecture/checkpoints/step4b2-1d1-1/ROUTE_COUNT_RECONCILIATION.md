## 2. Build Output Count Clarification

The build log line `Generating static pages (31/31)` represents the number of **static rendering jobs** performed by the Next.js build worker pool, which includes:
- 21 user-defined application page routes
- `/_not-found` framework route
- Additional internal Next.js framework rendering entries

This count must **not** be used as the authoritative application page count. The authoritative counts are **21 page routes** and **28 API route-handler paths**.
