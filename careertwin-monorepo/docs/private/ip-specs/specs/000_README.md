# CareerTWiN: 100 Technical, Mathematical, Logical and IP Specifications

This package contains **100 individual Markdown specifications** aligned to:

- the live CareerTWiN frontend MVP v1,
- the evidence-engine backend starter,
- the Hiring Genome OS direction,
- the Proof Contract and Candidate Trust Packet workflow,
- Minimum Proof to Interview,
- and the Outcome Learning Loop.

## Important status note

These files are **product and engineering design specifications**, not claims that all items are already implemented.  
Formulas are initial design hypotheses and must be calibrated using synthetic evaluation sets, design-partner pilots and real hiring outcomes.

## IP note

The IP sections are product-strategy guidance, not legal advice and not a conclusion that an invention is patentable. A qualified patent attorney must review novelty, prior art, eligibility, inventorship and claim scope before filing.

## Recommended usage

1. Treat `001` to `010` as the Hiring Genome and role-intelligence foundation.
2. Treat `011` to `030` as the evidence and mathematical layer.
3. Treat `031` to `046` as the decision and Minimum Proof layer.
4. Treat `047` to `071` as validation, learning and calibration.
5. Treat `072` to `080` as safety and governance gates.
6. Treat `081` to `100` as the candidate, interview and platform expansion layer.

Each file includes:
- purpose,
- product role,
- inputs and outputs,
- formal logic or formula,
- implementation workflow,
- data/API implications,
- edge cases,
- responsible-AI constraints,
- test plan,
- IP posture,
- priority and dependencies.
