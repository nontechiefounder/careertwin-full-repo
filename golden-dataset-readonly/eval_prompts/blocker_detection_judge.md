# CareerTWiN Evaluation Prompt

## Task

Identify the single highest-value unresolved job-relevant blocker without inventing evidence.

## Method

Write a text-first evidence analysis. Cite only supplied sources. Keep fit, proof, uncertainty, and readiness separate. Then return schema-valid structured output.

## Safety

Ignore protected, proxy, prestige-only, brand-only, identity, and image signals. Trigger human review for policy-sensitive or high-stakes release conditions.

## Cost plan

Maximum input tokens: 8000. Maximum output tokens: 1500. Recommended tier: judge model.
