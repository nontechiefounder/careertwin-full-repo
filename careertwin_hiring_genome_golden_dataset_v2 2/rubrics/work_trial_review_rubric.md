# Work-Trial Review Rubric

Score each dimension using Weak, Partial, Moderate, Strong, or Exceptional after writing evidence-grounded reasoning. Do not average away a critical contradiction.

## Dimensions

- **Problem Framing** — cite attributable sources and name uncertainty.\n- **Decision Quality** — cite attributable sources and name uncertainty.\n- **Verification** — cite attributable sources and name uncertainty.\n- **Ownership Boundary** — cite attributable sources and name uncertainty.\n- **Uncertainty** — cite attributable sources and name uncertainty.\n- **Communication** — cite attributable sources and name uncertainty.\n

## Release rule

Missing provenance, protected-signal use, or unsupported verified evidence requires withholding and human review.
